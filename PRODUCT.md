# PRODUCT.md - DeepChat Product Specifications

## Overview
DeepChat is an open-source, local-first and serverless-ready AI chat platform with streaming chat, code analysis, image generation, tools, and memory management.

## Capabilities & Features
- Model selection and platform-managed LLM endpoints.
- Real-time streaming chat completions with SSE.
- Code preview and sandboxed code execution.
- Chat history, pinned conversations, and shared chats.
- Data analysis, formula calculations, and spreadsheet exports.
- Temporary files and memory storage.
- Custom settings, persona customization, and storage management.
